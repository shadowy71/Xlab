What to observe

Continuous drive The driver repeats sinusoidally. The wave at a point farther right is the same motion delayed by x/v. Watch the phase lag from left to right: the pattern travels while individual particles oscillate vertically around equilibrium.

Fixed end The endpoint cannot move, so it is a node. The reflected pulse is inverted: a crest returns as a trough. The display adds an inverted, delayed copy of the source.

v = 1.20 m/s · γ = 0.35 s⁻¹ · λ = 1.20 m · changing mode or end restarts the trace.

Reduced motion is enabled: playback starts paused. Use Play when ready.

Reference

How to use this lab

  1. Choose a mode and a right end condition.
  2. Set amplitude, frequency, damping, tension, and playback speed.
  3. Use Play, Pause, Step, and Reset to control simulated time.
  4. In Pulse mode, use Send pulse; in Manual mode, use the driver slider or drag its handle.
  5. Turn the ruler, stopwatch, and reference guides on or off as needed.

Model assumptions

  • The string is 1.00 m long in model space. Red and cyan dots are neighboring particles with fixed horizontal positions; each moves only vertically around equilibrium. The disturbance travels; the particles do not travel with it.
  • A point at distance x shows the source delayed by x/v, where v = 1.20 √(T / 1.50 N) m/s. Tension is in model units with linear density held constant; it is not a calibration of a real string.
  • Damping uses e−γ·travel time. Oscillate drives a sine source; Pulse sends one smooth half-cycle whose duration is set by frequency; Manual records the driver position.
  • Fixed end adds an inverted delayed copy, loose end adds an upright delayed copy, and no end adds no reflection. Reflections fade in near the prescribed left driver.
  • The animation uses fixed 1/120 s steps and clamps frame delays to 50 ms. Changing mode or end condition restarts at t = 0; other control changes apply immediately to the current model.
